# ADR-001: Arquitetura em Camadas com Python, Streamlit, Pydantic e SQLite

## Contexto
O projeto DataStudy precisa gerenciar o ciclo de estudos, edital verticalizado, revisões espaçadas e métricas de desempenho com rápida entrega de interface (MVP), validação rigorosa de dados e persistência local confiável sem exigir servidor de banco de dados externo.

## Decisão
1. **Interface e Rotas (pp.py e pages/):** Uso do Streamlit multipágina para entrega ágil de formulários e dashboards interativos com Plotly, otimizados para uso desktop e mobile.
2. **Domínio e Serviços (src/datastudy/domain/ e services/):** Regras de negócio puras e modelos validados com Pydantic v2, totalmente isolados da camada de interface e do banco de dados.
3. **Repositório e Persistência (src/datastudy/repositories/):** Implementação do padrão Repository (SqliteRepository e JsonFileRepository) com consultas SQL parametrizadas (?) sobre SQLite nativo (sqlite3).

## Consequências
* **Positivas:** Alta testabilidade (28 testes automatizados com pytest rodando em segundos sem sujar dados reais usando 	mp_path); proteção nativa contra SQL Injection; facilidade de manutenção e deploy gratuito no Streamlit Community Cloud.
* **Negativas / Trade-offs:** O armazenamento local em arquivo requer rotina de backup e não é voltado para concorrência massiva multiusuário na mesma instância.
